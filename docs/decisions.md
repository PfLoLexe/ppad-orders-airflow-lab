# Согласованные решения

Пользователь утвердил предметную область заказов, генератор случайных данных с фиксируемым seed, модель покупателей/категорий/товаров/заказов/позиций, историю товаров SCD2 и статусов, семь групп метрик и объём 100 покупателей, 30 товаров, пять категорий, 1 000 заказов за 30 дней.

Каталог из `catalog-proposal.md` и учебные цены утверждены. Рабочий файл — `data/reference/catalog.json` со статусом `approved`. Файл `catalog.proposed.json` сохраняет предыдущий вариант предложения.

Утверждён отдельный Compose: PostgreSQL 512 МиБ, Airflow standalone 3 ГиБ, Metabase 1,5 ГиБ; отдельные служебные базы; интерфейсы привязаны к локальным портам. Разрешены необходимые установки на ВМ. Проект разворачивается в отдельной папке. Для публикации исходников пользователь разрешил создать независимый открытый GitHub-репозиторий.

## Связь с заданием

[Материалы преподавателя](https://github.com/kinomant/ppa-for-da/tree/master/airflow_workshop) описывают этапы STG, DDS, CDM и BI, работу Airflow и возможность использовать Metabase. В предоставленном блокноте DDS описан через третью нормальную форму, внешние ключи и SCD2. CDM должен строиться из DDS.

Наша реализация сохраняет исходные снимки в STG, нормализует детальные данные и ведёт историю в DDS, строит CDM исключительно из DDS и подключает BI к CDM. В README также упоминается история STG; у нас все версии полных снимков сохраняются по датам. История отдельных бизнес-сущностей реализована в DDS.

Точный перечень критериев оценки из плана занятий в доступных материалах не найден. Соответствие этим отдельным критериям нельзя утверждать без самого плана. Документы участников покрывают известные технические части лабораторной.
